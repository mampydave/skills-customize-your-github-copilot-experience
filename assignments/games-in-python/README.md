
# 📘 Assignment: Hangman Game

## 🎯 Objective

Practice Python fundamentals by building a text-based Hangman game that uses strings, loops, conditionals, and user input to create an interactive word-guessing experience.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Create a complete Hangman game where the player guesses letters to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly choose a word from a predefined list of words.
- Display the hidden word using underscores or blanks, such as `_ _ _ _`.
- Ask the user to enter one letter at a time and update the progress after each guess.
- Keep track of remaining incorrect guesses and show the updated status.
- End the game when the player correctly guesses the word or runs out of attempts.
- Display a clear win or lose message at the end of the game.

Example gameplay:

```python
Word: _ _ _ _ _
Guess a letter: a
Word: a _ _ _ _
Guess a letter: e
Incorrect guesses remaining: 5
```
