# 📘 Assignment: Python File Handling and Data Persistence

## 🎯 Objective

Learn how to read from and write to files in Python so your programs can save and retrieve information between runs.

## 📝 Tasks

### 🛠️ Read data from a file

#### Description
Create a program that reads information from a text file and prints or processes it.

#### Requirements
Completed program should:

- Open a file using Python's file-handling tools.
- Read the contents of the file and display them to the user.
- Handle the case where the file does not exist gracefully.
- Explain or print the data in a clear, readable format.

### 🛠️ Save user input to a file

#### Description
Build a small program that collects input from the user and saves it to a file for later use.

#### Requirements
Completed program should:

- Ask the user for a name, task, or other information.
- Save the data into a file such as `notes.txt` or `tasks.txt`.
- Append new entries instead of overwriting previous ones when appropriate.
- Show a confirmation message after saving.

### 🛠️ Practice data persistence

#### Description
Use file handling to create a simple persistent app that stores and loads information between runs.

#### Requirements
Completed program should:

- Create a small program such as a to-do list, journal, or student records tracker.
- Load existing data from a file when the program starts.
- Add new entries during the program run.
- Save the updated data back to the file before exiting.
- Handle common errors, such as missing files or invalid input.

Example output:

```python
Enter a task: Finish project
Task saved to tasks.txt
```
